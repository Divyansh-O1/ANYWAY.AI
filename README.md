# 🚀 ANYWAY AI

> A smart, lightweight AI chat interface built using pure HTML, CSS, and JavaScript  
> Created by **Divyansh**

---

## ✨ Features

- 💬 Advance style UI
- ⚡ Fast & lightweight (no frameworks)
- 🧠 Smart offline AI (no API required)
- 🔁 Remembers conversation (basic memory)
- 🧮 Can solve simple math
- 😂 Jokes & fun responses
- 💻 Basic coding help (HTML, CSS, JS)
- 🎬 Animated intro screen
